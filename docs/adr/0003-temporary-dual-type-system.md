# Temporary Dual Type System

app2 currently maintains its own Point, Line, Circle, Polygon, and CoordinateSystem interfaces (in app2/src/types/geometry.ts) alongside the @sg/geometry classes. This duplication existed because the Svelte app (now removed) depended on @sg/geometry, while app2's types enable the Step execution model with lazy evaluation and dependency tracking. With Svelte app removed, type system consolidation between app2 and @sg/geometry is now unblocked. We plan to evaluate which type system is better and consolidate, potentially migrating @sg/geometry to use app2's types or merging the best of both.
