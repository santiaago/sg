# Temporary Dual Type System

app2 currently maintains its own Point, Line, Circle, Polygon, and CoordinateSystem interfaces (in app2/src/types/geometry.ts) alongside the @sg/geometry classes. This duplication exists because the Svelte app (being deprecated) depends on @sg/geometry, while app2's types enable the Step execution model with lazy evaluation and dependency tracking. Once the Svelte app is removed, we plan to evaluate which type system is better and consolidate, potentially migrating @sg/geometry to use app2's types or merging the best of both. The current separation allows app2 to evolve its type system independently.
